# Bài tập Phát triển phần mềm hướng dịch vụ

## Chạy ứng dụng
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Mở http://127.0.0.1:5000, nhập dữ liệu và tải XML. File cũng được lưu trong outputs/.

WSDL là tài liệu mô tả giao diện minh họa, không phải SOAP server đang triển khai.
